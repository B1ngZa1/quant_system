# 功能演示脚本（项目卡 6）

## 演示目标

- 展示 DeepSeek/规则引擎在策略建议、事件分析、回测解读上的端到端输出。
- 展示 `/event` 与 `/ai` 页面在 Professional Finance Red 设计系统下的统一体验。

## 演示顺序（建议 8~10 分钟）

1. **开场（30s）**
   - 打开首页，说明系统定位：量化交易 + AI 增强分析。
2. **事件分析页 `/event`（3~4min）**
   - 输入新闻文本。
   - 点击“生成分析报告”。
   - 解读输出的 `entropy`、`sentiment`、`car_3d`、`risk_flags`、`trading_takeaways`。
3. **AI助手页 `/ai/assistant`（3~4min）**
   - 输入策略需求，点击“生成策略建议”。
   - 演示策略建议与代码模板输出。
   - 输入回测指标，点击“生成回测解读”。
4. **收尾（1min）**
   - 强调差异化：事件链路结构化、可解释、可执行。

## 输入样例

### A. 事件分析输入

- 关联标的：`600519`
- 事件文本：
  - `公司发布一季度业绩预告，营收同比增长18%，净利润同比增长22%，同时公告回购计划，总规模不超过30亿元。`

### B. AI策略建议输入

- 策略类型：`事件驱动`
- 策略描述：`关注政策催化和业绩超预期公告，寻求T+5窗口收益`
- 风险偏好：`medium`
- 关注标的：`000001,600519,300750`

### C. 回测解读输入

- 策略名称：`事件驱动策略A`
- 总收益率：`23.6`
- 年化收益率：`18.4`
- 最大回撤：`8.2`
- 夏普比率：`1.35`
- 胜率：`57`

## 预期输出要点

- `/event`：
  - 结构化输出含 `entropy`、`sentiment`、`car`。
  - 有可读风险提示和交易建议。
- `/ai/assistant`：
  - 能返回策略建议（DeepSeek可用时优先AI文本）。
  - 能返回回测解读（文本化结论 + 指标回显）。
