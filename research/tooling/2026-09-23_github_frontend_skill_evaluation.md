## 设计决策（本项目推断）

对象是研究员使用的量化研究与模拟回测系统，首屏任务是看清数据可用性、继续研究、进入可复核的结果。旧设计的问题不是色彩不够深，而是示意收益曲线与虚构活动造成“模板 Dashboard”观感，同时字号过密、空数据时仍占据右侧资讯栏。

- 色板：深海军蓝 `#07111f` 为画布，墨蓝 `#0c1928` 为面板，稍亮的 `#102238` 为研究焦点；钴蓝 `#3a7bfd` 仅用于主操作与可选项；文字 `#e6edf6`、次级文字 `#b4c1d0`。红涨绿跌继续沿用项目金融语义，不用颜色单独传达状态。
- 字体：保持已有中英系统字体栈；研究焦点标题 32–46px、模块标题 16px、正文 13–14px、辅助信息 11–12px；资金和百分比使用等宽数字。避免加载外部字体导致中文回退不稳定。
- 栅格：左侧固定导航；主区域先状态带，再研究焦点；只有真实资讯时才启用右侧栏。记录表只展示真实回测；空态用三步研究路径表达下一步，不生成任何虚构曲线。

```text
┌──────── 左导航 ────────┬────────────────── 主工作区 ──────────────────┐
│ 模块与研究入口          │ 页面标题 / 明确研究边界                       │
│                        │ 指数行情或数据状态                             │
│                        │ ┌──── 回测观察：真实曲线 / 可行动空态 ────┐  │
│                        │ └─────────────────────────────────────┘  │
│                        │ 最近回测记录（仅真实数据） / 资讯状态           │
└────────────────────────┴──────────────────────────────────────────────┘
```

视觉自检：移除首页对示意图表、固定活动时间和假收益的引用；让错误、空数据与未登录各自有可解释文案；主操作清晰、边界说明可见；小屏时焦点面板改为纵向布局，移动导航提供遮罩与 Escape 关闭。

## 数据事实与限制

- `GET /v1/backtest/list` 是已存在、需认证的项目接口，按创建时间倒序返回当前用户回测，列表含收益指标与 `equity_curve`。资金曲线仅在真实点数至少 2 个时绘制；登录态和真实记录本轮未伪造。
- 主要指数及资讯由项目原有 API 提供。请求失败与返回空列表分开显示；行情趋势缺失时不再用两点水平线假造走势。
- 本轮未连接实盘、未发送订单、未使用真实密钥、未删除旧示意组件文件。浏览器对已登录且含真实回测的数据分支没有可用账号，因此该分支以 API 契约、静态类型与构建验证，仍需有数据环境复核。
