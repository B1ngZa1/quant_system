# 离线市场—财务仪表盘：技术与可视化设计

## 目标与阅读路径

**分析任务：** 解释量化交易软件为何存在可变现需求、为何交易活动不能替代软件 TAM，以及三类可比商业模式在利润、现金转化和研发投入上的差异。

**主张：** 交易活动证明工作流需求；高利润取决于订阅/数据/基础设施型收入及成本控制；客户结算类现金流不能与纯软件现金流混同比较。

**阅读顺序：** 先看四个不可相加的市场活动卡片，再看三家公司统一百分比口径的横向条形图，最后看证据、口径与限制。所有关键数值均直接显示，不依赖悬停。

## 技术设计

| 维度 | 决策 |
| --- | --- |
| 交付面 | 一个独立、离线 HTML 文件；一页最多 1 个 SVG 图、4 个市场卡片和 1 张语义表。 |
| 数据与交互 | 12 个市场 CSV 行与三家公司的已核验派生指标；无远程请求、无自动刷新、无动画、无过滤器或悬停依赖。 |
| 大屏与移动 | ≥860px 为两列；<860px 为单列，SVG 可横向滚动，信息表不裁剪；不需要移动端单独手势。 |
| 状态与持久化 | 没有交互状态，因此不使用 URL 查询参数、localStorage、IndexedDB 或远程存储；锚点链接可定位“来源与口径”。 |
| 渲染架构 | 纯语义 HTML/CSS 加内嵌 SVG；SVG 负责一个百分比坐标系的条形图，HTML 表格作为可访问且可复制的备用表示。 |
| 可访问性 | SVG 含 `title`、`desc` 和 `role=img`；图表后提供同值表格；颜色只用作辅助编码；浅色背景与深色文字保持高对比。 |
| 性能与维护 | 少于 40 个可视标记、无依赖、无网络与无脚本，主线程/内存/带宽成本可忽略；源数据或口径变化时同步更新嵌入数值、表格和 `market_research.csv`/`financials_normalized.csv`。 |
| 首选/备用 | 首选为该离线 SVG 报告；备用为 `2026-09-22_quant_trading_software_market_financial_v1.md` 和两份源 CSV。 |

## 可视化选择与限制

- 市场活动的币种、资产类别和时间粒度不同，使用**独立卡片**而非共用轴，避免制造可比性的错觉。
- 三家公司的净利率、经营现金流/净利润和研发/营收均为百分比，可共享以零为中心的横轴；负现金转化以向左的条形与负号直接展示。
- 两项第三方市场估计来自不同研究机构与期末，只在文本中作为外部区间线索呈现，不以趋势线或 CAGR 显示。
- 页面为 2026-09-22 快照，不构成实时市场数据、产品预测、投资建议或交易授权。
