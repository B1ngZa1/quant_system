# Papers

保存论文原件、元数据和引用清单。原件与摘要/笔记分开，不把论文正文复制进代码或表格。

当前 `raw/` 已下载 10 篇可追溯开放版本，页数、文件大小和 SHA-256 见 `metadata/download_manifest.csv`。下载文件仅用于本地研究，引用和再分发须遵守原始来源条款。

`references.csv` 与 `metadata/papers.json` 当前对齐 16 条记录；`metadata/search_log.csv` 记录按强化学习、执行、多智能体、风险和回测偏差主题整理的检索批次。未落盘的论文只代表已编目，不代表已取得全文或再分发许可。

`notes/` 保存项目映射和复现边界，`evidence/` 预留页码级证据索引；二者均不替代 PDF 原件或来源台账。
