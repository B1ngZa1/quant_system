# 文献证据摘录索引

本目录将保存对本地可访问文献的页码级证据索引，而非大段转载原文。每个条目应记录：

| 字段 | 说明 |
| --- | --- |
| `source_id` | 对应 `references.csv` 的唯一来源 ID |
| `local_path` | 已校验的 PDF 路径 |
| `page_or_section` | 可复查的页码、公式、表格或章节 |
| `claim_type` | 方法、假设、数据、成本、验证或局限 |
| `project_decision` | 该证据影响的模型/实验设计决定 |
| `quote_or_paraphrase` | 最小必要的合规摘录或释义 |
| `replication_requirement` | 在项目中重用前的输入、许可或检验条件 |

没有本地 PDF、未取得许可或尚未逐页审阅的条目不得填写为“已验证证据”。
